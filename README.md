eMATINO 🛡️
Empowering Media Awareness Through Integrity, Navigation, and Online Responsibility

A cybersecurity awareness website built as a final project for Introduction to Computing at Batangas State University — The National Engineering University.

📖 About the Project
eMATINO is a static multi-page website designed to promote digital literacy and cybersecurity awareness among students and everyday internet users. The site provides educational resources, awareness tips, and blog articles to help users navigate the digital world safely and confidently.

🌐 Pages
Page	File	Description
Home	index.html	Landing page with cybersecurity overview, common threats, and protection tips
About	about.html	Team info, mission, vision, and developer profiles
Blogs	blogs.html	Curated external articles on digital literacy and cybersecurity
Awareness Tips	awarenesstips.html	10 actionable tips for staying safe online
Let’s Connect	letsconnect.html	Login/registration page for the platform
✨ Features
Responsive multi-page layout using HTML and CSS
Navigation bar consistent across all pages
Background video on the home page hero section
Flip card animations for developer profiles (About page)
Embedded external article links on the Blogs page
Table of Contents with anchor links on the Home page
Social media icon links in the footer
Google Maps integration via “Locate Us” button
🛠️ Tech Stack
HTML5 — Page structure and content
CSS3 — Styling, animations, and layout (separate .css file per page)
Google Fonts — Poppins font family
Font Awesome 4.7 — Social media and UI icons
Vanilla JS — None used; fully static site

🚀 Getting Started
This is a static website — no installation or build tools required.

Clone or download the repository.
Open index.html in any modern web browser.
Navigate through the site using the top navigation bar.
Note: Some features (background video, images) require the videos/ and images/ folders to be present alongside the HTML files.
