🛡️ MATINISTA — eMATINO

Empowering Media Awareness Through Integrity, Navigation, and Online Responsibility

eMATINO is a cybersecurity awareness website developed as a final project for Introduction to Computing at Batangas State University — The National Engineering University.

📖 About the Project

eMATINO is a static multi-page website designed to promote digital literacy and cybersecurity awareness among students and everyday internet users.

The website provides educational resources, cybersecurity awareness tips, and curated blog articles to help users navigate the digital world safely, responsibly, and confidently.

🌐 Website Pages
Page	File	Description
🏠 Home	index.html	Landing page featuring a cybersecurity overview, common threats, and protection tips
👥 About	about.html	Team information, mission, vision, and developer profiles
📰 Blogs	blogs.html	Curated external articles related to digital literacy and cybersecurity
🛡️ Awareness Tips	awarenesstips.html	10 actionable tips for staying safe online
🔗 Let's Connect	letsconnect.html	Login and registration page for the platform
✨ Features
📱 Responsive multi-page layout using HTML and CSS
🧭 Consistent navigation bar across all pages
🎥 Background video in the Home page hero section
🔄 Flip-card animations for developer profiles on the About page
🔗 Embedded external article links on the Blogs page
📑 Table of Contents with anchor links on the Home page
📱 Social media icon links in the footer
📍 Google Maps integration through the "Locate Us" button
🎨 Dedicated CSS files for individual pages
⚡ Fully static website with no backend or build process

🚀 Getting Started

eMATINO is a static website, so no installation, dependencies, or build tools are required.

1. Clone the Repository
git clone https://github.com/your-username/your-repository.git

2. Open the Project

Navigate to the project directory:

cd eMATINO

3. Launch the Website

Open index.html in any modern web browser.

You can then navigate through the website using the navigation bar.

Note: For all images and background videos to display correctly, make sure the images/ and videos/ folders remain in the same directory as the HTML files.
